# Вікі: пошук готових рішень для розробки

## Ресурс

**Awesome Agent Skills** — велика колекція офіційних Agent Skills (готових "навичок" для AI-агентів: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Windsurf тощо). Понад 1497 готових рішень від провідних команд розробки (Anthropic, Google, Vercel, Stripe, Cloudflare, Netlify, Hugging Face, Figma та ін.) і від спільноти. Зручно використовувати як стартову точку пошуку готового рішення замість написання з нуля.

🔗 Репозиторій: https://github.com/VoltAgent/awesome-agent-skills

## Як користуватись

1. Перейти за посиланням репозиторію або обраної категорії вище.
2. Знайти навичку (skill), що відповідає задачі розробки.
3. Підключити навичку у свій AI-асистент (Claude Code, Cursor, Copilot тощо) за інструкцією з відповідного репозиторію навички, замість написання рішення з нуля.

*Примітка: у цього репозиторію GitHub API не надає прямого доступу до вбудованої GitHub Wiki (окремий git-репозиторій `*.wiki.git`, для якого в цій сесії немає облікових даних), тож список додано як файл `WIKI.md` у корені репозиторію.*
