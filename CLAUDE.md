## Інструменти / інтеграції

### Planfix MCP

Planfix (CRM/PM-платформа, основний інструмент crmcustoms) має офіційний
MCP-сервер. Довідка: https://planfix.com/uk/help/MCP (домен заблоковано
egress-проксі цієї сесії — сторінку не вдалось відкрити напряму; перед
першим реальним підключенням звірити деталі нижче за цим посиланням або
попросити користувача вставити текст сторінки).

**Суть методу підключення** (по аналогії з тим, як влаштована решта
інтеграцій Planfix — REST API з ключем на кожен акаунт):

- Planfix — мультитенантна SaaS: кожен клієнт має свій акаунт на власному
  піддомені (`<account>.planfix.com`).
- MCP-сервер Planfix підключається як звичайний remote MCP-конектор
  (у Claude: Settings → Connectors → Add custom connector), а не як
  локальний процес.
- Авторизація прив'язана до конкретного акаунта: або OAuth-логін в цей
  акаунт під час підключення конектора, або API-ключ, згенерований у
  налаштуваннях самого акаунта (Адміністрування → API). Один конектор =
  один Planfix-акаунт.
- Після підключення MCP дає доступ до сутностей акаунта (задачі, контакти,
  угоди/CRM, проєкти) без окремого написання інтеграції під кожного
  клієнта.

**Як підключати нові акаунти тим самим методом:**

1. У новому/іншому Planfix-акаунті зайти в адмін-розділ і згенерувати
   API-ключ (або пройти OAuth-логін саме під цим акаунтом — залежно від
   того, що фактично пропонує форма підключення на сторінці довідки).
2. Додати ще один MCP-конектор (Settings → Connectors → Add custom
   connector), вказавши адресу Planfix MCP-сервера для цього акаунта.
3. Авторизувати конектор ключем/логіном саме цього акаунта — попередній
   конектор іншого клієнта не чіпати, вони незалежні.
4. Перевірити доступ простим запитом (наприклад, список задач) перед тим,
   як віддавати клієнту.

Коли користувач каже "підключись до мого Planfix" — це і є профіль
підключення вище: питати треба лише сам ключ/акаунт, а не яким
інструментом користуватись.
